panels, and top-down sequence diagrams with real-case branches. All are
generated by [`scripts/gen-prize-diagrams.py`](../scripts/gen-prize-diagrams.py)
(edit the text data in that script, run it, every diagram regenerates).

## Reading notes

- **Flows** run top-to-bottom; the right-hand column carries per-section
  details (constraints, measured numbers, design rules).
- **Sequences** run top-to-bottom (time); gold kickers mark real-case branches,
  dashed arrows are returns/reads, bold arrows are user-visible payoffs.
- The master map is the authoritative integration picture — every arrow is an
  implemented call path in `src/loci/`.
